# 服务启动事项

本地联调前按本文启动与核对。**端口与默认 API 地址为约定配置，未经确认不要改。**

相关文档：`platform/README.md`、`platform/docs/local-runbook.md`。

---

## 1. 端口约定（勿随意改）

| 服务 | 端口 | 地址 | 说明 |
|------|------|------|------|
| Platform Nest API | **8080** | `http://127.0.0.1:8080` | Flutter `ENV=local` 默认后端 |
| App API | 8080 | `http://127.0.0.1:8080/api/v1` | App 业务接口 |
| Admin API | 8080 | `http://127.0.0.1:8080/api/admin/v1/...` | 管理端（经 Vite 代理） |
| Health | 8080 | `http://127.0.0.1:8080/health` | 探活 |
| Admin Web (Vite) | **5173** | `http://127.0.0.1:5173` | 管理台；`/api` → `8080` |
| 旧 Express Mock | **3847** | `http://127.0.0.1:3847/api/v1` | `server/`；活动页 / 下载等兜底 |
| Postgres | 5432 | `127.0.0.1:5432` | Platform 数据库 |
| MinIO | 9000 / 9001 | — | 可选对象存储 |

Flutter 常量（`lib/core/constants/hos_constants.dart`）：

- `defaultLocalApiBaseUrl` → **`http://127.0.0.1:8080/api/v1`**（Platform）
- `localMockServerPort` → **3847**（旧 mock，与 local 默认 URL 不是同一套）

> Android 模拟器访问本机：把 `127.0.0.1` 换成 `10.0.2.2`。

## 2. Flutter 环境与启动逻辑

启动参数：`--dart-define=ENV=...`、`USE_MOCK_API=...`、`API_BASE_URL=...`。

实现：`lib/core/config/hos_config.dart`、`hos_environment.dart`。

### 2.1 `ENV` 怎么选

| ENV | 含义 | `useMockApi`（未强制覆盖时） | 默认 `apiBaseUrl` |
|-----|------|------------------------------|-------------------|
| 空 + Debug | 等同 **dev** | `true`（内置 Dio Mock） | `https://mock.shoo.local/api/v1`（占位，实际走拦截器） |
| **dev** | 开发 / 内置 Mock | `true` | 同上 |
| **local** | 连本机真实 HTTP | **强制 `false`** | `http://127.0.0.1:8080/api/v1` |
| staging / prod | 预发 / 正式 | staging 可 mock；prod 否 | 各自远程地址 |

关键规则：

1. **`ENV=local` → 一定不走内置 Mock**，必须有本机 API（默认 8080）。
2. 非 local 时，`USE_MOCK_API=true/false` 才生效；默认未传时为 `true`。
3. 显式传 `API_BASE_URL=...` 会覆盖该环境的默认 Base URL。
4. Debug 面板可运行时切环境；切到 local 同样关闭 Mock 并指向 local 默认 URL。

### 2.2 推荐启动方式

**只跑 App、不依赖本机 Nest（内置 Mock）：**

```bash
cd SHOO
flutter run
# 或
flutter run --dart-define=ENV=dev --dart-define=USE_MOCK_API=true
```

**联调 Platform（Admin + Nest + App）：**

```bash
# 先按第 3 节起 Postgres → API:8080 → Admin:5173，再：
cd SHOO
flutter run \
  --dart-define=ENV=local \
  --dart-define=USE_MOCK_API=false \
  --dart-define=API_BASE_URL=http://127.0.0.1:8080/api/v1
```

**仅需旧 Express Mock（活动资源 / 特殊场景）：**

```bash
cd SHOO/server && npm run dev   # :3847
flutter run \
  --dart-define=ENV=local \
  --dart-define=USE_MOCK_API=false \
  --dart-define=API_BASE_URL=http://127.0.0.1:3847/api/v1
```

注意：3847 与 8080 **不要混用默认值**；改默认常量前必须先问清楚。

## 3. Platform 启动顺序（Admin `5173` + API `8080`）

按顺序执行；Admin 依赖 API，缺 8080 时首页刷新会出现 **banners 500 / 网络错误**。

### 3.1 数据库

```bash
cd SHOO/platform/deploy/docker
docker compose up -d postgres minio
```

无 Docker 时本地 Postgres：`user/password/db = shoo/shoo/shoo`，端口 `5432`。

### 3.2 Nest API（必须）

```bash
cd SHOO/platform/apps/api
cp -n .env.example .env   # 首次
npm install
npx prisma db push
npm run seed              # 首次或 mock JSON 变更后
npm run start:dev         # 监听 8080
```

探活：

```bash
curl http://127.0.0.1:8080/health
curl http://127.0.0.1:8080/api/v1/banners
```

期望：`{"code":0,...}`，HTTP 200。

### 3.3 Admin Web

```bash
cd SHOO/platform/apps/admin-web
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

打开：`http://127.0.0.1:5173` 或 `http://localhost:5173/home`  
账号：`admin@shoo.local` / `admin123456`

Vite 将 `/api` 代理到 `http://127.0.0.1:8080`（见 `vite.config.ts`）。

代理探活：

```bash
curl -sS -o /dev/null -w "%{http_code}\n" http://localhost:5173/api/v1/banners
# 期望 200
```

### 3.4 Flutter（local）

见 **§2.2** 联调 Platform 命令。

## 4. 旧 Mock Server（可选，`server/` :3847）

```bash
cd SHOO/server
npm install
npm run dev
```

探活：`curl http://127.0.0.1:3847/health`

用途：历史 Express mock、活动页静态资源、部分下载/音乐路径。  
**日常 Admin + App 联调以 Platform 8080 为准。**

## 5. 启动检查清单

每次联调前快速打勾：

- [ ] Postgres 已起（`5432`）
- [ ] `platform/apps/api` → `npm run start:dev`，`curl :8080/health` = 200
- [ ] `curl :8080/api/v1/banners` = 200
- [ ]（需要管理台）Admin `:5173` 已起，`curl localhost:5173/api/v1/banners` = 200
- [ ] Flutter：`ENV=local` + `USE_MOCK_API=false` + Base URL 指向 **8080**（除非明确要用 3847）
- [ ]（可选）旧 mock `:3847` 仅在需要时启动

## 6. 常见故障

| 现象 | 常见原因 | 处理 |
|------|----------|------|
| Admin `/home` 刷新 banners **500** | Nest `:8080` 未启动或挂了 | 起 API；再刷 5173 |
| App「网络错误」、首页拉不到数据 | `ENV=local` 但 8080 未起；或 Base URL 被改成 3847/错误端口 | 起 API；核对 `API_BASE_URL` / `defaultLocalApiBaseUrl` |
| 登录后重启又像未登录 | Session 恢复依赖 profile；API 不可达且无本地用户缓存 | 保证 8080 可用；重新登录一次写入缓存 |
| Android 模拟器连不上本机 | 仍用 `127.0.0.1` | 改为 `http://10.0.2.2:8080/api/v1` |
| `Cannot GET /api/admin/v1/banners` | 路径应为 `/api/admin/v1/catalog/banners` | 以 Admin 前端实际请求为准 |

## 7. 改端口 / 默认 URL 的纪律

以下变更**必须先询问并得到确认**后再做：

- `8080` / `5173` / `3847` / `5432` / `9000` 等监听端口
- `defaultLocalApiBaseUrl`、`localMockServerPort`、Vite `proxy`、API `.env` 的 `PORT`
- 文档或脚本里把 Platform 默认从 8080 改成 3847（或反过来）

允许不询问的：在命令行**临时** `--dart-define=API_BASE_URL=...` 做一次联调实验（不改仓库默认值）。
