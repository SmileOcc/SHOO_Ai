# bridge — 基础 Channel 通信层

Platform Channel 底层封装，供业务与 Hybrid 层复用。

## 文件清单

| 文件 | 职责 |
|------|------|
| `hos_channel_names.dart` | 通道名常量（`native_bridge` / `native_host` / `native_event` / `native_message`） |
| `hos_native_bridge.dart` | **MethodChannel** 泛型调用（`call` / `invoke`）、统一日志与异常 |
| `hos_native_bridge_exception.dart` | 原生桥统一异常 `SHONativeBridgeException` |
| `hos_native_type_caster.dart` | 原生返回值类型安全转换 |
| `hos_native_message_bridge.dart` | **BasicMessageChannel** 双向小数据（Echo、心跳） |
| `hos_native_event_bridge.dart` | **EventChannel** 流封装（`broadcast` / `collect` / `cancelSafely`） |
| `hos_native_stream_service.dart` | Event 订阅基类，dispose 时自动 cancel |
| `hos_native_device_service.dart` | 示例：`ping` / `getPlatformVersion` |

## 通道方向

| 通道 | Dart API | 典型场景 |
|------|----------|----------|
| `native_bridge` | `SHONativeBridge` | Flutter → Native 一次性调用 |
| `native_message` | `SHONativeMessageBridge` | 双向轻量 JSON |
| `native_event` | `SHONativeEventBridge` | Native → Flutter 流式推送 |

## 使用示例

```dart
// MethodChannel
final version = await SHONativeBridge.call<String>(method: 'getPlatformVersion');

// BasicMessageChannel
final echo = await SHONativeMessageBridge.send<Map>(message: {'text': 'hi'});

// EventChannel
final events = await SHONativeEventBridge.collect(maxEvents: 3);
```
