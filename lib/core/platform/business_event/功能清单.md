# business_event — 原生业务事件

基于 `EventChannel` 的支付、下载、物流等业务事件模型与服务。

## 文件清单

| 文件 | 职责 |
|------|------|
| `hos_native_event_kinds.dart` | 事件种类常量（`payment` / `download` / `logistics` / `debug_tick`） |
| `hos_native_business_event.dart` | 统一事件模型 `SHONativeBusinessEvent` |
| `hos_native_business_event_service.dart` | 按业务订阅：`watchPayment` / `watchDownload` / `watchLogistics` |

## 事件参数编码

`watch(kind, params)` 将参数编码为 EventChannel 参数字符串：

```
payment:orderId=ORD001
download:taskId=mock_download
logistics:orderId=ORD001
```

## 使用场景

| 方法 | 场景 |
|------|------|
| `watchPayment` | 支付结果轮询 / 回调 |
| `watchDownload` | 文件下载进度 |
| `watchLogistics` | 物流轨迹实时推送 |

## 使用示例

```dart
ref.read(nativeBusinessEventServiceProvider)
    .watchLogistics(orderId: orderId)
    .listen((event) { /* 更新 UI */ });
```
