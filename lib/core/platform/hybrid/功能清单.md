# hybrid — 混合桥（S活动）

Flutter 主应用 + 原生 iOS 混合交互：S活动瀑布流、原生 Push Flutter 页、弹窗实验。

> 详细设计见同目录 `SHO_HYBRID_BRIDGE.md`

## 文件清单

| 文件 | 职责 |
|------|------|
| `hos_hybrid_bridge_protocol.dart` | method / dialog kind 协议常量 |
| `hos_hybrid_bridge.dart` | 门面：`openSActivity()` / `openDialogLab()` |
| `hos_hybrid_bridge_installer.dart` | 应用根部安装宿主通道 + 路由监听 |
| `hos_native_host_bridge.dart` | 注册 `native_host` MethodChannel Handler |
| `hos_native_host_actions.dart` | 处理 navigate / showDialog / Channel Demo / 嵌入 Pop |
| `hos_hybrid_native_overlay_coordinator.dart` | 嵌入 Push 会话：Flutter pop ↔ 原生 Nav pop 同步 |
| `hos_hybrid_native_overlay_provider.dart` | Riverpod 监听 go_router 变化 |

## 通道分工

| 通道 | 方向 | 用途 |
|------|------|------|
| `native_bridge` | Flutter → Native | `sActivity/open`、`sActivity/popHybridPage` |
| `native_host` | Native → Flutter | `navigate`、`showDialog`、`onHybridFlutterPopped` |

## S活动 功能地图

| 区块 | 实现 |
|------|------|
| 交换学习 ×3 | 原生 UI → `native_host` 演示三种 Channel |
| F商品列表 | 原生 Nav Push `HybridFlutterRouteViewController` → go_router |
| F购物车 | 同上 → `/cart/view` |
| S弹弹窗 | 原生页按钮 → Flutter `SHOAppDialog` → 结果回显 |

## 嵌入导航流程

```
S活动 (原生 Nav 栈底)
  → push HybridFlutterRouteViewController (共享 Engine)
  → native_host navigate(route, embedded: true)
  → go_router.push(route)
  → 返回时：router.pop + native popHybridPage → 回到 S活动
```

## 原生对应

- `HybridBridgeCoordinator.swift` — 协调器
- `HybridFlutterRouteViewController.swift` — Push 的 Flutter 容器
- `SActivityViewController.swift` — S活动主页
- `SDialogLabViewController.swift` — 弹窗实验
