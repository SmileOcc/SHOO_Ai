# native_components — 原生组件库

百宝箱「原生组件组」对应的 Flutter 桥接与 iOS 原生 Demo 实现。

## Dart 文件

| 文件 | 职责 |
|------|------|
| `hos_native_components_protocol.dart` | module id / method 常量 |
| `hos_native_components_bridge.dart` | `openHub()` / `runModule(id)` |

## 组件列表

| module id | 功能 | iOS 实现要点 |
|-----------|------|----------------|
| `map` | 地图 | `MKMapView` |
| `video` | 视频播放 | `AVPlayerViewController` |
| `webView` | WebView | `WKWebView` |
| `push` | 推送 | `UNUserNotificationCenter` 本地通知 |
| `payment` | 支付 | 模拟支付确认弹窗 |
| `socialLogin` | 社交登录 | Sign in with Apple + 微信/QQ 桩 |
| `analytics` | 原生埋点 | 调用 Flutter `SHOAnalyticsManager` |
| `photoLibrary` | 相册读写 | `PHPickerViewController` |
| `keychain` | Keychain | `Security` 读写演示 |
| `nfc` | NFC | `NFCNDEFReaderSession`（设备支持时） |
| `bluetooth` | 蓝牙 | `CBCentralManager` 扫描 |
| `appBadge` | 应用角标 | `applicationIconBadgeNumber` |
| `share` | 原生分享 | `UIActivityViewController` |

## Channel

| 方向 | method | 说明 |
|------|--------|------|
| Flutter → Native | `nativeComponents/open` | 打开原生 Hub |
| Flutter → Native | `nativeComponents/run` | 直接运行指定 module |
| Native → Flutter | `trackNativeAnalytics` | 埋点 Demo 回传 Flutter |

## 百宝箱入口

`hos_toolbox_page.dart` → 「原生组件」分组 → `SHONativeComponentsBridge.openHub()`（仅 iOS）

## 原生文件（iOS）

- `NativeComponentsCoordinator.swift`
- `NativeComponentsHubViewController.swift`
- `NativeComponentDemos.swift`
